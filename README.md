# Yerel Klavye Olay Laboratuvari

Bu proje GUI ile çalışmayacak şekilde üretimiştir çünkü projenin amacına uymaz.
LLM ile ortak çalışma ve algoritma testi geliştirilme sürecinde olduğu için LLM'lerin farkedip edemeyeceklerini test edilmesi gerekir.

- `raw.txt`: Tus olaylari (`selan[SILME TUSU]m`)
- `resolved.txt`: Olaylar uygulandiktan sonraki metin (`selam`)

Python 3 ile Windows'ta `python app.py`, Linux'ta `python3 app.py` komutuyla calistirilabilir.
